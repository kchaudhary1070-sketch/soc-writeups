## What I learned
- Task 2: The Terminal is the interface application that displays the command-line window, whereas the Shell (e.g., Bash) is the underlying interpreter that processes commands and passes them to the operating system kernel.
• First Command Executed: pwd (or whoami) to check the current working directory and user identity.
- Task 3: Navigation Commands: Used pwd to view the current path, ls to list contents, cd [directory] to move forward into folders, and cd .. to move up one level.
- Task 4: • System Search: I used grep to search for text within files, I found grep easy to use because The result came out very fast, so I didn't even need to open the file. 
• Feedback: Very efficient and faster than a graphical interface once basic syntax is understood.
- Task 5: Pipes: Passed output between commands using the Pipe operator (|).
- Task 6: Completion & Feedback (Practice Arena): Successfully executed practice exercises, gaining practical fluency in chaining basic commands for effective control.


## Key takeaway
- Linux treats everything as a file, offering complete system control and powerful automation directly through the terminal.
