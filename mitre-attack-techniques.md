## T1110 - Brute Force
- ID: T1110
- Tactic: Credential Access
- Sub-techniques:
  - T1110.001 - Password Guessing
  - T1110.002 - Password Cracking
  - T1110.003 - Password Spraying
  - T1110.004 - Credential Stuffing
- Meaning: When someone repeatedly tries to log in with wrong passwords until they succeed, it is called a brute force attack.

## T1078 - Valid Accounts
- ID: T1078
- Tactics: Stealth, Persistence, Privilege Escalation, Initial Access
- Sub-techniques:
  - T1078.001 - Default Accounts
  - T1078.002 - Domain Accounts
  - T1078.003 - Local Accounts
  - T1078.004 - Cloud Accounts
- Meaning: Attacker uses a real user's valid username and password to log in, so the system treats him as a normal user.

## T1566 - Phishing
- ID: T1566
- Meaning: Attacker tricks the user with a fake email, message or website to steal login details or make them open a malicious file.

## T1021 - Remote Services
- ID: T1021
- Meaning: Attacker uses remote access services like SSH or RDP to log in to another system.

## T1190 - Exploit Public-Facing Application
- ID: T1190
- Meaning: Attacker uses a weakness (vulnerability) in an application open to the internet, like a website or server, to get inside.
