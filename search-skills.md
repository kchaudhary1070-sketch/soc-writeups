## What I learned
- Task 2: Shodan is often described as a search engine for the Internet of Things (IoT), but that undersells it. Shodan continuously scans the internet, searching for networking equipment, industrial control systems, traffic cameras, and virtually anything else with a public network connection to see what's running and where.
- Task 3: VirusTotal collates results from over 70 antivirus engines and website scanners into a single interface. Submit a file, a URL, a domain, or a file hash. VirusTotal will tell you whether any of those engines have flagged it as malicious or not.
- Task 4: CVE meaning The Common Vulnerabilities and Exposures (CVE) programme is the closest thing the industry has to a universal dictionary of known vulnerabilities.
- Task 5: The man command (short for manual) in Linux is used to display the user manual of any command, utility, or function that you can run in the terminal ,Think of it as your built-in offline encyclopedia or instruction manual for Linux commands.
- Task 6: GitHub can be a great resource for staying updated on the latest threats and vulnerabilities. Researchers often publish proof-of-concept (PoC) code, exploitation tools, and detailed technical reports there, which are usually faster than official channels. 

## Key takeaway
- In my opinion, VirusTotal is the most useful tool because a SOC analyst's daily workflow involves quickly checking incoming suspicious files, links, or IPs to determine whether they are malicious. VirusTotal accomplishes this task in just a matter of moments.
